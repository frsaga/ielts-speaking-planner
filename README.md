# IELTS Speaking Planner

A self-contained practice planner with question filtering, progress and study plans. The public sample contains three original demonstration questions; private question banks and personal study history are not included.

Run `python3 build_site.py`, then open index.html. Use `--questions-json your-local-questions.json` for your own data. Optional XLSX import uses `--workbook your-file.xlsx` and requires openpyxl. Do not commit private learning records or exports.
